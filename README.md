Mental Health Text Classification using DistilBERT

NLP pipeline that fine-tunes a pretrained DistilBERT model to classify text into four categories: **Normal, Depression, Suicidal, or Anxiety**, using the Hugging Face.

Features:
 * Encoder-only sequence classification
 * Dynamic Padding:
 * Overfitting Protection:

Dataset
 * ourafla/Mental-Health_Text-Classification_Dataset (Hugging Face Hub)
